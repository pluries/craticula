AG Grid Server-Side Row Model, compilé

Requêtes AG Grid en entrée.
Requêtes sûres en sortie.

Craticula compile les requêtes AG Grid en requêtes natives SQL, MongoDB et OpenSearch. Il ne les exécute jamais, et chaque valeur est un paramètre lié.

Commencer par le démarrage rapide Lire la vue d'ensemble

  • Essayer en lignePostgreSQLMongoDB

Apache-2.0 · .NET 10

Requête AG Grid
{
  "startRow": 0, "endRow": 50,
  "filterModel": {
    "customer": { "type": "contains", "filter": "acme" },
    "amount": { "type": "greaterThan", "filter": 100 }
  },
  "sortModel": [ { "colId": "amount", "sort": "desc" } ]
}
Instruction compilée et paramètres
SELECT * FROM "orders"
WHERE ("customer" ILIKE '%' || $1 || '%' ESCAPE '\'
   AND "amount" > $2::numeric)
ORDER BY "amount" DESC NULLS FIRST, "id" ASC NULLS LAST
LIMIT $3 OFFSET $4

-- parameters: 'acme', '100', 50, 0

De l'installation à votre première requête

  1. Étape 1

    Installer

    Compilez la bibliothèque depuis les sources et référencez le projet correspondant à votre moteur.

  2. Étape 2

    Déclarer un GridSchema

    Listez les champs qu'une grille peut toucher, car tout le reste est refusé.

  3. Étape 3

    Compiler une requête

    Passez la requête AG Grid en entrée et obtenez une instruction et ses paramètres en sortie.

  4. Étape 4

    L'exécuter

    Exécutez-la avec votre propre connexion, ou laissez un adaptateur le faire.
