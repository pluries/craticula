AG Grid Server-Side Row Model, compilado

Solicitudes de AG Grid de entrada.
Consultas seguras de salida.

Craticula compila las solicitudes de AG Grid en consultas nativas de SQL, MongoDB y OpenSearch. Nunca las ejecuta, y cada valor es un parámetro enlazado.

Solicitud de AG Grid
{
  "startRow": 0, "endRow": 50,
  "filterModel": {
    "customer": { "type": "contains", "filter": "acme" },
    "amount": { "type": "greaterThan", "filter": 100 }
  },
  "sortModel": [ { "colId": "amount", "sort": "desc" } ]
}
Sentencia compilada y parámetros
SELECT * FROM "orders"
WHERE ("customer" ILIKE '%' || $1 || '%' ESCAPE '\'
   AND "amount" > $2::numeric)
ORDER BY "amount" DESC NULLS FIRST, "id" ASC NULLS LAST
LIMIT $3 OFFSET $4

-- parameters: 'acme', '100', 50, 0
