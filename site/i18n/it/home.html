AG Grid Server-Side Row Model, compilato

Richieste AG Grid in ingresso.
Query sicure in uscita.

Craticula compila le richieste AG Grid in query native SQL, MongoDB e OpenSearch. Non le esegue mai, e ogni valore è un parametro associato.

Richiesta AG Grid
{
  "startRow": 0, "endRow": 50,
  "filterModel": {
    "customer": { "type": "contains", "filter": "acme" },
    "amount": { "type": "greaterThan", "filter": 100 }
  },
  "sortModel": [ { "colId": "amount", "sort": "desc" } ]
}
Istruzione compilata e parametri
SELECT * FROM "orders"
WHERE ("customer" ILIKE '%' || $1 || '%' ESCAPE '\'
   AND "amount" > $2::numeric)
ORDER BY "amount" DESC NULLS FIRST, "id" ASC NULLS LAST
LIMIT $3 OFFSET $4

-- parameters: 'acme', '100', 50, 0

Dall'installazione alla prima query

  1. Passo 1

    Installare

    Compilare la libreria dai sorgenti e fare riferimento al progetto corrispondente al proprio motore.

  2. Passo 2

    Dichiarare un GridSchema

    Elencare i campi che una griglia può usare, perché tutto il resto viene rifiutato.

  3. Passo 3

    Compilare una richiesta

    Fornire la richiesta AG Grid in ingresso e ottenere in uscita un'istruzione con i relativi parametri.

  4. Passo 4

    Eseguirla

    Eseguirla con la propria connessione, oppure lasciare che lo faccia un adattatore.
