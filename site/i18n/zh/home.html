AG Grid Server-Side Row Model，编译而成

AG Grid 请求进。
安全查询出。

Craticula 把 AG Grid 请求编译为原生的 SQL、MongoDB 和 OpenSearch 查询。它绝不执行这些查询，并且每个值都是绑定参数。

从快速入门开始 阅读概览
  • 安装dotnet add package Craticula.Corenuget.org
  • 在线试用PostgreSQLMongoDB

Apache-2.0 · .NET 10

AG Grid 请求
{
  "startRow": 0, "endRow": 50,
  "filterModel": {
    "customer": { "type": "contains", "filter": "acme" },
    "amount": { "type": "greaterThan", "filter": 100 }
  },
  "sortModel": [ { "colId": "amount", "sort": "desc" } ]
}
编译后的语句和参数
SELECT * FROM "orders"
WHERE ("customer" ILIKE '%' || $1 || '%' ESCAPE '\'
   AND "amount" > $2::numeric)
ORDER BY "amount" DESC NULLS FIRST, "id" ASC NULLS LAST
LIMIT $3 OFFSET $4

-- parameters: 'acme', '100', 50, 0
