AG Grid Server-Side Row Model, kompiliert

Anfragen von AG Grid hinein.
Sichere Abfragen heraus.

Craticula kompiliert Anfragen von AG Grid zu nativen Abfragen für SQL, MongoDB und OpenSearch. Es führt sie nie aus, und jeder Wert ist ein gebundener Parameter.

Mit dem Schnellstart beginnen Die Übersicht lesen
  • Installierendotnet add package Craticula.Corenuget.org
  • Online ausprobierenPostgreSQLMongoDB

Apache-2.0 · .NET 10

Anfrage von AG Grid
{
  "startRow": 0, "endRow": 50,
  "filterModel": {
    "customer": { "type": "contains", "filter": "acme" },
    "amount": { "type": "greaterThan", "filter": 100 }
  },
  "sortModel": [ { "colId": "amount", "sort": "desc" } ]
}
Kompilierte Anweisung und Parameter
SELECT * FROM "orders"
WHERE ("customer" ILIKE '%' || $1 || '%' ESCAPE '\'
   AND "amount" > $2::numeric)
ORDER BY "amount" DESC NULLS FIRST, "id" ASC NULLS LAST
LIMIT $3 OFFSET $4

-- parameters: 'acme', '100', 50, 0

Von der Installation zur ersten Abfrage

  1. Schritt 1

    Installieren

    Kompilieren Sie die Bibliothek aus dem Quellcode und referenzieren Sie das Projekt für Ihre Engine.

  2. Schritt 2

    Ein GridSchema deklarieren

    Listen Sie die Felder auf, die ein Grid berühren darf, denn alles andere wird abgelehnt.

  3. Schritt 3

    Eine Anfrage kompilieren

    Übergeben Sie die Anfrage von AG Grid und erhalten Sie eine Anweisung samt Parametern zurück.

  4. Schritt 4

    Ausführen

    Führen Sie sie mit Ihrer eigenen Verbindung aus oder überlassen Sie das einem Adapter.
