AG Grid server-side row model, compiled

AG Grid requests in.
Safe queries out.

Craticula compiles AG Grid requests into native SQL, MongoDB and OpenSearch queries. It never runs them, and every value is a bound parameter.

Start with the quickstart Read the overview Pre-release: build from source, no package published yet. Apache-2.0 · .NET 10
AG Grid request
{
  "startRow": 0, "endRow": 50,
  "filterModel": {
    "customer": { "type": "contains", "filter": "acme" },
    "amount": { "type": "greaterThan", "filter": 100 }
  },
  "sortModel": [ { "colId": "amount", "sort": "desc" } ]
}
Compiled statement and parameters
SELECT * FROM "orders"
WHERE ("customer" ILIKE '%' || $1 || '%' ESCAPE '\'
   AND "amount" > $2::numeric)
ORDER BY "amount" DESC NULLS FIRST, "id" ASC NULLS LAST
LIMIT $3 OFFSET $4

-- parameters: 'acme', '100', 50, 0
