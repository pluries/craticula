# SEC-2 lint allowlist for the TypeScript query builders (scripts/lint-sec2-ts.py): the reviewed trust boundaries.
#
# Two kinds of entry, one per line ('#' starts a comment):
#   trust <file> | <expression> | <reason>   the exact expression (whitespace collapsed) is accepted as it stands in that file
#   skip-file <file> | <reason>               the file builds no query text
#
# Add an entry only for a value that is NOT a user value: a quoting or placeholder primitive's own input, a parameter that
# arrives already quoted from the one function that quotes it, or text that never reaches a query. A user value in query text
# is a SEC-2 defect to fix, never an entry here. An entry that matches nothing in the run fails it, so this file cannot rot.

# -- Files that build no query text.
skip-file typescript/src/sql/values.ts | builds the text of a bound datetime value and error messages; the result is a parameter, never query text (SEM-4)
skip-file typescript/src/sql/escape.ts | escapes a pattern value that is bound as a parameter; escaping does not make it query text (SEM-7, SQL-5)

# -- SQL-1 quoting primitives: the one place an identifier meets its delimiter, which each dialect doubles.
trust typescript/src/sql/postgres.ts | identifier.replaceAll('"', '""') | the quoting primitive doubles '"' inside "..." (SQL-1)
trust typescript/src/sql/sqlite.ts | identifier.replaceAll('"', '""') | the quoting primitive doubles '"' inside "..." (SQL-1)
trust typescript/src/sql/oracle.ts | identifier.replaceAll('"', '""') | the quoting primitive doubles '"' inside "..." (SQL-1)
trust typescript/src/sql/mysql.ts | identifier.replaceAll("`", "``") | the quoting primitive doubles '`' inside `...` (SQL-1)
trust typescript/src/sql/mssql.ts | identifier.replaceAll("]", "]]") | the quoting primitive doubles ']' inside [...] (SQL-1)

# -- Placeholder primitives: an ordinal the parameter bag counts, never a value (the value went to the parameter list).
trust typescript/src/sql/postgres.ts | ordinal + 1 | the 1-based number of $n, from the bag's own parameter count (SEC-2)
trust typescript/src/sql/mssql.ts | ordinal + 1 | the 1-based number of @pn, from the bag's own parameter count (SEC-2)
trust typescript/src/sql/oracle.ts | ordinal + 1 | the 1-based number of :pn, from the bag's own parameter count (SEC-2)

# -- The column arrives already quoted: the builder's columnOf is the one function that quotes a schema name and passes it to a dialect.
trust typescript/src/sql/postgres.ts | column | the dialect methods receive a column quoted by the builder (SQL-1)
trust typescript/src/sql/mssql.ts | column | the dialect methods receive a column quoted by the builder (SQL-1)
trust typescript/src/sql/mysql.ts | column | the dialect methods receive a column quoted by the builder (SQL-1)
trust typescript/src/sql/oracle.ts | column | the dialect methods receive a column quoted by the builder (SQL-1)
trust typescript/src/sql/sqlite.ts | column | the dialect methods receive a column quoted by the builder (SQL-1)
trust typescript/src/sql/builder.ts | column | the column is built by columnOf, which quotes it, or passed in by a caller that did (SQL-1)

# -- Conditions the builder rendered itself.
trust typescript/src/sql/builder.ts | predicate | the parameter of nullInclusive and the local of where: a condition rendered by this builder, already made of placeholders and quoted names
trust typescript/src/sql/postgres.ts | placeholder | the parameter of the pattern helper and the local of the dialect method: the placeholder bind returned
trust typescript/src/sql/mssql.ts | placeholder | the parameter of the pattern helper and the local of the dialect method: the placeholder bind returned
trust typescript/src/sql/mysql.ts | placeholder | the parameter of the pattern helper and the local of the dialect method: the placeholder bind returned
trust typescript/src/sql/oracle.ts | placeholder | the parameter of the pattern helper and the local of the dialect method: the placeholder bind returned
trust typescript/src/sql/sqlite.ts | placeholder | the parameter of the pattern and collation helpers: the placeholder bind returned

# -- An output name, quoted by quoteIdentifier wherever it becomes SQL.
trust typescript/src/sql/grouping.ts | aggregation.field | the default output name is a schema field name plus a function name; the builder quotes it (SQL-1, AGG-2)
trust typescript/src/sql/grouping.ts | aggregation.func | the aggregation function is one of the closed set sum, min, max, avg, count (AR-8)

# -- SQLite's GLOB escaping: the characters of a pattern VALUE, which is then bound, never spelled into the text.
trust typescript/src/sql/sqlite.ts | character | escapeGlob wraps a wildcard character of the bound pattern value in brackets (SQL-5)
